# App de Pedido de Pizza

Aplicativo Android que simula um pedido em uma pizzaria. O usuário escolhe o tipo de pizza, tamanho e método de pagamento, e o app exibe um resumo com o valor total.

---

## 🏗️ **Tecnologias Utilizadas**
- **Linguagem:** Java
- **IDE:** Android Studio
- **Interface:** XML

---

  ## 🏗️ Funcionalidades:
- **Activity 1**: Seleção do tipo de pizza via CheckBoxes (ex: Calabresa, Marguerita, Portuguesa).
- **Activity 2**: Escolha do tamanho (Pequena, Média, Grande) e do método de pagamento (Dinheiro, Cartão) via RadioButtons.
- **Activity 3**: Mostra o tipo de pizza, tamanho, forma de pagamento e valor total do pedido.
